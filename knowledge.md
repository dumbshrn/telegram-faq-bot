## Nightly / Beta Builds

If the Automatic Nightly Git Build is down:
1. Go to the Gitapks channel
2. Download the latest compiled APK

If the Nightly Git Builder is available:
- Inside the app: Settings > System update > turn on Beta Updates >
  tap System Update to check for updates
- Or via the website: visit https://vivimusic.mkmdevilmi.workers.dev/,
  click Download, then "Download Beta"

Note: check the pinned comments (wherever nightly builds are announced)
to see if the nightly build is currently down.

## Playback Issues (song won't play / stuck / errors)

Troubleshooting steps, in order:
1. Update to the latest nightly build from the Gitapks channel
2. Force stop the app and check again
3. If songs still won't play, try logging out and back in
4. Go to Settings > Content > switch between IPv4 and IPv6 (make sure
   proxy is enabled)
5. Clear app data — don't restore from backup — and try using the app
   without an account first, to see if it works
6. Add your account back and check if it's working
7. If not, try logging in with a different account and check
8. Still not working? Record logs using the "Logcat Reader" app (on
   Play Store), then share the logcat file in the group — it helps
   fix the issue faster
9. Please report the issue in the group after sharing the logcat

## Importing Spotify Playlists

1. Go to Settings > Backup and restore
2. Select Spotify, then select all the playlists you want to import
3. To also sync those playlists to YouTube Music: after importing,
   hold on a specific playlist, and you'll see an option to "sync to
   YouTube Music" — tap it. Your playlist will then be available in
   the cloud too, and any new songs you add to that playlist will
   keep syncing.

## Apple Music-style UI

- Apple Music V17 look: Settings > Appearance > Player > select
  "Apple Music v17" (disables the newer player design)
- Apple Music V1 look: Settings > Appearance > Player > select
  "Apple Player" (disables the newer player design). This also
  removes the audio quality badge if that's bothering you.
